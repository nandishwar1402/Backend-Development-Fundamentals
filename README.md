## Project Description
This project demonstrates how to create a basic web server using Node.js and Express.js.

## Features
- Home route (`/`)
- About route (`/about`)
- Time route (`/time`)
- Custom 404 error page

## Technologies Used
- Node.js
- Express.js
- JavaScript

## Installation
```bash
npm install
```

## Run the Server
```bash
node app.js
```

## Local URL
http://localhost:3000/
